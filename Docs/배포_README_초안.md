# Reisa_Archive

블루 아카이브 비공식 팬게임입니다. 비영리로 배포되며, 원작 「블루 아카이브」의 모든 권리는 NEXON에 있습니다.

## 다운로드

오른쪽 **Releases**에서 최신 버전의 `Reisa_Archive_Windows.zip`을 받아 압축을 풀고 `Reisa_Archive` 폴더 안의 `Reisa_Archive.exe`를 실행하세요.

## 업데이트 방법

새 버전의 zip을 받아, 기존 `Reisa_Archive` 폴더에 그대로 **덮어쓰기**하면 됩니다. 아이템 도감 기록은 게임 폴더가 아닌 곳에 저장되어 있어 그대로 유지됩니다.

## 실행 시 "Windows의 PC 보호" 경고가 뜰 때

개인이 만든 게임이라 코드 서명이 되어 있지 않아 Windows가 경고를 띄웁니다. **추가 정보 → 실행**을 누르면 실행됩니다.

## 플레이 통계 수집 및 업데이트 확인 안내

이 게임은 밸런스 조정과 버그 수정을 위해 **익명 플레이 기록**을 전송합니다.

- **보내는 것:** 게임이 무작위로 만든 식별 번호, 게임 버전, 판 기록(시작·종료 방식, 플레이 시간, 진행 레벨, 사망 위치와 원인, 획득·보유 아이템, 아이템 도감 기록), 게임 오류 내용
- **보내지 않는 것:** 이름, 계정, IP 주소, PC 이름, 사용자 이름, 파일 경로 등 개인을 알 수 있는 정보
- 시작 화면에서 새 버전이 있는지 확인하기 위해 GitHub에 최신 버전 번호를 요청합니다. 새 버전이 있으면 알림 창이 뜨고, 다운로드는 직접 하셔야 합니다(자동 설치 없음).
- 게임은 기록을 보내고 버전 번호를 확인하기만 하며, 외부에서 받은 내용으로 PC에서 아무것도 실행하지 않습니다.
