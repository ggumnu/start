//   3    카메라  흔들림  0.1  0.5초            세기(m), 시간
//   2    카메라  따라가기  플레이어            거리/방향을 유지하며 따라감 (해제: 카메라 따라가기 해제)

//   0    플레이어  등장  P1                    P1 자리에, P1이 향한 방향으로 섬
//   1    플레이어  걷기  P1 > P2 > P3          '걷기 P2'처럼 하나만 적으면 지금 자리에서 P2로
//   1    플레이어  뛰기  P1 > P2
//   4    플레이어  보기  P4  0.5초              '보기 카메라'면 카메라 쪽
//   5    플레이어  장전  1.5초
//   7    플레이어  포즈  짜잔                   전신 포즈 / '포즈 획득' = 상체만
//   9    플레이어  대기  0.6초                  포즈/장전을 풀고 대기 자세로

//   -- 적 배우 (장면의 Props 안에 놓은 적 프리팹. 이름 자리에 그 오브젝트 이름, 적이 하나뿐이면 '보스' / '적'도 됨) --
//   0    보스  확산충전  2초                   전방위 공격의 충전만 보여 주고 쏘지 않음
//   0    보스  확산공격                        충전 -> 발사 -> 회전 ('확산공격 충전 0.3초'로 충전 시간 변경)

//   8    끝                                   장면 끝 (녹화도 여기서 멈춤)
//   속도 낱말: 부드럽게(기본) / 일정하게 / 가속 / 감속
//   0    플레이어  조준  0.1초                  총 조준 자세 ('조준 해제'로 풀기)
//   0.2  시간  0.15배                         세상(플레이어/적/총알)의 빠르기. 여러 줄이면 그 사이를 부드럽게 이음(카메라는 영향 없음)
