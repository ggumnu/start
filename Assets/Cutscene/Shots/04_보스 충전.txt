//   0    카메라  A                           구도 A로 바로 전환
//   0.5  카메라  A > B  3초  부드럽게         A에서 B로 3초 동안 이동 (A > B > C 도 가능)
//   4    카메라  > C  2초                     지금 위치에서 C로 이동
//   0    카메라  바라보기  P1  높이 0.3  1초    P1을 계속 바라봄 (마지막 숫자 = 시선이 옮겨가는 시간)
//   6    카메라  바라보기  해제  1초
//   2    카메라  돌기  P1  90도  3초  높이 1.5  P1 주위를 돎 (+ = 위에서 볼 때 시계 방향, 높이 = 올라가는 양)
//   2    카메라  줌  40  2초                  화각을 40으로
//   3    카메라  흔들림  0.1  0.5초            세기(m), 시간
//   2    카메라  따라가기  플레이어            거리/방향을 유지하며 따라감 (해제: 카메라 따라가기 해제)
//   0    화면  밝게  1초   /   화면  어둡게  1초
//   -- 플레이어 (바라보기/돌기/따라가기의 대상 이름 자리에 '플레이어'를 쓸 수 있음) --
//   0    플레이어  등장  P1                    P1 자리에, P1이 향한 방향으로 섬
//   1    플레이어  걷기  P1 > P2 > P3          '걷기 P2'처럼 하나만 적으면 지금 자리에서 P2로
//   1    플레이어  뛰기  P1 > P2
//   4    플레이어  보기  P4  0.5초              '보기 카메라'면 카메라 쪽
//   5    플레이어  장전  1.5초
//   7    플레이어  포즈  짜잔                   전신 포즈 / '포즈 획득' = 상체만
//   9    플레이어  대기  0.6초                  포즈/장전을 풀고 대기 자세로
//   3    플레이어  표정  획득  2초              기본 / 피격 / 획득 / 장전 / 사망 / 뛰기
//   8    끝                                   장면 끝 (녹화도 여기서 멈춤)
//   속도 낱말: 부드럽게(기본) / 일정하게 / 가속 / 감속
//   -- 적 배우 (장면의 Props 안에 놓은 적 프리팹. 이름 자리에 그 오브젝트 이름, 적이 하나뿐이면 '보스' / '적'도 됨) --
//   0    보스  확산충전  2초                   전방위 공격의 충전만 보여 주고 쏘지 않음
//   0    보스  확산공격                        충전 -> 발사 -> 회전 ('확산공격 충전 0.3초'로 충전 시간 변경)
//   1    보스  공격취소  /  보스  보기  플레이어  0.5초  /  보스  이동  E1 > E2  2초
